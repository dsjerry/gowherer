# 选包规则

## 首选判断

1. 只要用户在当前项目里要“接入高德地图”，先看他需要的是哪一层能力。
2. 默认优先推荐最小依赖，不要一上来把三个包都装上。

## 包的用途

- `expo-gaode-map`
  - 地图显示
  - 定位
  - 覆盖物
  - 离线地图
  - 内置原生搜索

- `expo-gaode-map-navigation`
  - 导航 UI
  - 路径规划
  - 车机/导航场景
  - 也带地图能力

- `expo-gaode-map-web-api`
  - 纯 JavaScript 的地理编码、POI、输入提示、路径规划等
  - 作为补充包使用

## 互斥规则

- `expo-gaode-map` 和 `expo-gaode-map-navigation` 不要同时安装。
- 如果用户已经选了导航包，就不要再补装核心包。
- 如果用户只做搜索、地址解析、路线服务，且不需要原生地图视图，可以考虑只用 Web API。

## 推荐问法

- “我要在现有 Expo 项目里显示地图并打点”
- “我要做导航页和路径规划”
- “我要用高德 Web API 做地址搜索”
